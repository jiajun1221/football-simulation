# Core model categories

All models retain the `FootballSimulation.Models` namespace.

- `Competitions` - leagues, fixtures, tables, and season archives
- `Match` - match state, events, options, substitutions, summaries, and weather
- `Players` - player identity, positions, traits, form, injuries, and statistics
- `Tactics` - formations, mentality, tactical options, presets, and team tactics
- `Teams` - teams and club news
- `Persistence` - save-game and save-slot data contracts
- `Transfers` - transfer-market data contracts
- `Youth` - youth academy data contracts
