# Core service categories

All services retain the `FootballSimulation.Services` namespace. The folders group related behavior without coupling the simulation layer to a UI.

- `Competitions` - league, cup, calendar, awards, and season progression
- `Data` - loading, persistence, saves, nationalities, and venue data
- `Game` - game-session, news, and tactical analysis
- `Match` - match setup, events, fitness, discipline, statistics, and analysis
- `Players` - player attributes, form, growth, contracts, and traits
- `Squads` - formations, lineups, positions, roster selection, and AI management
- `Transfers` - finances, loans, free agents, valuations, and transfer windows
- `Youth` - academies, scouting, youth generation, and youth valuation
