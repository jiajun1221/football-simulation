# View categories

All views retain the `FootballSimulation.Wpf.Views` namespace and keep each XAML file beside its code-behind file.

- `Shell` - menus, dashboard, save loading, and team selection
- `Match` - pre-match, live match, halftime, penalties, and results
- `Squad` - squad overview, player statistics, and youth academy
- `Season` - team results, end-of-season results, and celebrations
- `Transfers` - transfer market screens, panels, dialogs, and notifications
